آزمایشگاه تیا
=============
سایت فارسی و راست‌به‌چپ، آماده انتشار روی GitHub Pages.

انتشار: همه فایل‌ها را در ریشه مخزن بگذار و از Settings ← Pages شاخه اصلی را انتخاب کن.
برای سئو، در فایل‌های sitemap.xml و (در صورت تمایل) یک تگ canonical در index.html، آدرس USERNAME/REPO را با آدرس واقعی سایت عوض کن.

ساختار: index.html (رابط و ۸۰ بخش) · assets/mathcore.js (هسته محاسباتی: میلر–رابین، پولارد رو، غربال قطعه‌ای، مارپیچ) · assets/engines.js (موتورهای شبیه‌سازی) · assets/fx.js و fx.css (جلوه‌ها).
